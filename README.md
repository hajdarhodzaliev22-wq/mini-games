## 📝 Описание игр
В этом проекте собраны следующие игры:
1. **Угадай число** — классическая игра на угадывание случайного числа.
2. **Камень, Ножницы, Бумага** — игра против компьютера.
3. **Викторина** — проверь свои знания.
4. **Крестики-нолики** — игра для двоих (в консоли).
5. **Виселица** — угадай слово по буквам.
6. **Бросок кубика** — симулятор игральных костей.

Также включен `index.html` для веб-презентации проекта.

## 🚀 Как запустить

### Требования
- Установленный Python 3.x

### Инструкции
1. Клонируйте репозиторий:
```bash
   git clone https://github.com/your-username/mini-games.git
   cd mini-games
```

2. Запустите главное меню:
```bash
   python main.py
```

3. Или запускайте отдельные игры из папки `games`:
```bash
   python games/game1_guess_number.py
```
